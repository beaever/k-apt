# K-apt 아스콘 입찰 정보 수집기

[K-apt(공동주택관리정보시스템)](https://www.k-apt.go.kr)에서 아스콘(아스팔트 콘크리트) 공사 낙찰 공고를 검색하고,
공고문(첨부파일 또는 외부 원문)에서 자본금·실적·공법번호 같은 비정형 요건을 자동으로 추출해
엑셀 파일로 내려받는 웹 서비스입니다.

## 주요 기능

- 지역(서울/인천/경기), 검색어, 검색 기간(직접 지정, 최대 1년)으로 낙찰 공고 검색
- 검색 결과 페이지네이션을 전부 순회해 조건에 맞는 **모든** 공고 수집 (건수 제한 없음)
- 공고 상세페이지 접속 후 아파트명/세대수/낙찰업체/낙찰금액 등 자동 추출
- 첨부된 입찰공고문(HWP/PDF) 자동 다운로드 후 텍스트 추출
- K-apt 자체 첨부파일이 없는 공고는 "해당 공고 가기"를 통해 외부 대행 사이트(a2p.kr, kg2b.com 등)의
  원문 공고서까지 따라가서 확보
- 공고문 텍스트에서 자본금 / 실적 / 공법(특허)번호 요건을 정규식으로 추출
- 값을 찾지 못한 경우 빈 칸이 아니라 **왜 못 찾았는지 구체적인 사유**를 표시
  (첨부파일 없음 / 다운로드 실패 사유 / 지원하지 않는 파일 형식 / 문서에 해당 문구 없음 등)
- 5개 공고를 동시에 처리하는 병렬 크롤링으로 속도 개선 (워커별 독립 브라우저 세션 사용)
- 결과를 화면 표로 즉시 확인 (성공/실패 건수, 실패 행 빨간색 강조) + 엑셀 다운로드

## 기술 스택

| 영역 | 기술 |
|---|---|
| 백엔드 | Python, FastAPI, Playwright(Chromium), pdfplumber, pyhwp, BeautifulSoup4, openpyxl |
| 프런트엔드 | Next.js(App Router), React, TypeScript, Tailwind CSS |

인증/결제 기능은 포함하지 않습니다.

## 프로젝트 구조

```

    app/
      main.py              # FastAPI 앱, /api/collect(작업 시작) · /api/collect/{id}(상태 조회) 엔드포인트

        step1_search.py    # K-apt 접속 → 지역/검색어/기간 필터 → 목록 수집(페이지네이션 전체)
```

## 내 컴퓨터에서 사용하기 (비개발자용 안내)

개발 지식이 없어도 아래 순서대로 **복사 → 붙여넣기 → 엔터**만 하면 됩니다.
처음 한 번만 하는 "설치"와, 쓸 때마다 하는 "실행"으로 나뉩니다.

> macOS 기준으로 확인한 절차입니다. Windows는 명령어가 다른 곳만 따로 적어두었습니다.

### 용어 3개만 알고 가기

- **터미널**: 글자로 컴퓨터에 명령을 내리는 창입니다.
  - macOS: `⌘ + Space` → "터미널" 입력 → 엔터
  - Windows: 시작 메뉴 → "PowerShell" 검색 → 실행
- **명령어 붙여넣기**: 아래 회색 상자 안의 글자를 복사해 터미널에 붙여넣고 엔터를 누릅니다.
  줄이 여러 개면 한 줄씩 넣어도 되고 한꺼번에 넣어도 됩니다.
- **프로그램 끄기**: 실행 중인 터미널 창에서 `Ctrl + C` 를 누릅니다.

### 1단계. 필요한 프로그램 설치 (처음 한 번만)

아래 두 프로그램을 공식 사이트에서 받아 일반 프로그램처럼 설치합니다. (설치 화면에서 계속 "다음")

| 프로그램 | 받는 곳 | 비고 |
|---|---|---|
| Python | https://www.python.org/downloads/ | 노란 "Download Python" 버튼. **Windows는 설치 첫 화면에서 "Add python.exe to PATH" 체크 필수** |
| Node.js | https://nodejs.org/ | "LTS"라고 적힌 버튼 |

설치 확인: 터미널을 **새로 열고** 아래를 입력했을 때 버전 숫자가 나오면 성공입니다.

```bash
python3 --version
node --version
```

(Windows는 `python3` 대신 `python --version`)

### 2단계. 프로젝트 파일 받기 (처음 한 번만)

1. https://github.com/beaever/k-apt 접속 (로그인이나 GitHub 계정 없이 받을 수 있습니다)
2. 초록색 **Code** 버튼 → **Download ZIP**
3. 받은 ZIP 파일의 압축을 풀고, 폴더 이름을 `k-apt` 로 바꾼 뒤 **바탕화면(Desktop)** 에 둡니다.

> git을 쓸 줄 안다면 `git clone https://github.com/beaever/k-apt.git` 로 받아도 됩니다.

### 3단계. 설치 명령 실행 (처음 한 번만, 5~10분)

터미널을 열고 아래를 붙여넣습니다. 인터넷에서 필요한 부품과 크롬 브라우저 엔진을 내려받습니다.

**macOS**

```bash
cd ~/Desktop/k-apt/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
playwright install chromium
cd ../frontend
npm install
```

**Windows (PowerShell)**

```powershell
cd ~\Desktop\k-apt\backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
cd ..\frontend
npm install
```

- 글자가 많이 올라가는 건 정상입니다. 마지막에 다시 입력 대기 상태가 되면 끝난 것입니다.
- Windows에서 `venv\Scripts\activate` 가 "스크립트를 실행할 수 없습니다" 오류를 내면,
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 입력하고 `Y` 를 누른 뒤 다시 시도하세요.

### 4단계. 실행하기 (쓸 때마다)

**터미널 창 2개**가 필요합니다. 둘 다 켜둔 상태로 사용하고, 창을 닫으면 프로그램도 꺼집니다.

**창 ① — 수집 서버** (공고 검색/다운로드/분석 담당)

```bash
cd ~/Desktop/k-apt/backend
source venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 8420
```

(Windows: 두 번째 줄을 `venv\Scripts\activate` 로)

`Application startup complete.` 가 보이면 준비 완료입니다.

**창 ② — 화면** (새 터미널 창을 하나 더 열어서)

```bash
cd ~/Desktop/k-apt/frontend
npm run dev
```

`Ready` 가 보이면 준비 완료입니다.

**브라우저(크롬 등)에서 http://localhost:3000 접속** → 검색 화면이 나옵니다.

> 주소는 꼭 `localhost` 로 입력하세요. `127.0.0.1:3000` 으로 들어가면 화면이 계속 새로고침될 수 있습니다.

다 쓰고 나면 두 터미널 창에서 각각 `Ctrl + C` 를 누르거나 창을 닫으면 됩니다.

### 5단계. 사용하기

1. 지역(서울/인천/경기)을 체크합니다.
2. 검색어를 입력합니다. (예: "아스콘")
3. 기간을 고릅니다. 빠른 선택(1주일/1개월/1년) 버튼을 눌러도 됩니다. (최대 1년)
4. **검색 시작**을 누릅니다.
   - 진행 상황("12/40건")이 표시됩니다. 1개월치 기준 수 분, 1년치는 수십 분 걸릴 수 있습니다.
   - 진행 중에는 브라우저 탭을 닫지 마세요. (수집 서버 창 ①도 켜둔 채로)
5. 끝나면 결과 표와 정상/실패 건수가 나오고, **엑셀 다운로드** 버튼으로 파일을 받을 수 있습니다.
   (브라우저의 기본 다운로드 폴더에 저장됩니다)

### 결과 보는 법

| 보이는 값 | 뜻 | 할 일 |
|---|---|---|
| 상태 **정상** | 모든 칸이 공고문에서 확인된 값 | 그대로 사용 |
| **해당 없음(공고문에 관련 요건 없음)** | 공고문에 그 요건 자체가 없음 (예: 특허 요건이 없는 공고) | 그대로 사용 |
| 상태 **실패** (빨간 줄) | 한 칸 이상을 확신할 수 없음. 상태 칸에 이유가 적혀 있음 | "원문 보기" 링크로 원문 확인 |
| **[확인 필요] 문장** | 관련 문장은 찾았지만 금액/건수/특허번호가 없어 확신할 수 없음 | 적힌 문장을 보고 판단, 애매하면 원문 확인 |

### 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| `command not found: python3` / `node` | 1단계 설치 후 **터미널을 완전히 닫았다 다시** 열기 |
| 설치 중 `[notice] A new release of pip is available` | 오류 아님. 무시하면 됨 |
| `No such file or directory` (cd 할 때) | 2단계에서 폴더 이름이 `k-apt` 이고 바탕화면에 있는지 확인 |
| `address already in use` | 이미 켜진 창이 있다는 뜻. 기존 터미널 창을 닫고 다시 실행 |
| 화면에서 "다른 수집 작업이 진행 중입니다" | 한 번에 하나만 수집 가능. 진행 중인 작업이 끝날 때까지 기다리기 |
| 화면에서 "요청 실패" / 아무 반응 없음 | 창 ① 수집 서버가 켜져 있는지 확인 |
| 화면에서 "수집 중 오류가 발생했습니다" | K-apt 사이트가 일시적으로 느린 경우가 많음. 잠시 후 다시 시도 |
| 전에 받은 엑셀을 다시 받으려는데 안 됨 | 결과 파일은 24시간 뒤 자동 삭제됨. 다시 검색 |

### 개발자용 실행 요약

```bash
# backend
cd backend && python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt && playwright install chromium
uvicorn app.main:app --host 127.0.0.1 --port 8420

# frontend (백엔드 주소가 기본값과 다르면 .env.example -> .env.local 복사 후 NEXT_PUBLIC_API_BASE 수정)
cd frontend && npm install && npm run dev
```

HWP 텍스트 추출은 `pyhwp`가 설치하는 `hwp5html` CLI를 사용합니다(venv 활성화 없이 실행해도 venv 안의 것을 찾음).

엑셀/결과 표의 컬럼: 공고일자 / 아파트명 / 공사명 / 세대수 / 자본금 / 실적 / 공법번호 /
낙찰방법 / 낙찰업체 / 낙찰금액 / 공고 링크 / 상태

**상태 판정 기준**: 크롤링 도중 예외가 났는지만 보지 않고, **10개 데이터 컬럼이 전부 확인된
값인지**로 정상/실패를 가립니다. 자본금/실적/공법번호는 키워드가 있는 줄이라도 아래 값이 있어야
"확인된 값"으로 인정합니다.

| 컬럼 | 인정 조건 | 조건 미달 시 |
|---|---|---|
| 자본금 | 금액(예: 5억, 500,000,000원) | `[확인 필요] 원문 문장` |
| 실적 | 건수(N건/회) 또는 금액 | `[확인 필요] 원문 문장` |
| 공법번호 | 특허·실용신안 등록번호(10-/20-XXXXXXX), 문서 전체에서 탐색 | `[확인 필요] 공법 문장` |

- 공고문 전체에 관련 문구(자본금 / 실적·최근 N년간 / 특허·공법·신기술·실용신안)가 전혀 없으면
  **"해당 없음"**으로 채우고 정상으로 봅니다. 단, 텍스트를 뽑지 못한 첨부파일(스캔 PDF 등)이 하나라도
  있으면 단정하지 않고 실패로 둡니다.
- 따라서 **"정상" 행은 원문을 열지 않아도 되고, "실패" 행만 "공고 링크"로 확인**하면 됩니다.
  (실제 공고 32건 검증: 29건 정상, 실패 3건은 모두 원문 자체가 모호하거나 스캔 PDF인 경우)

**자동 추출은 100%가 아닙니다.** 정규식 파싱은 문서 표현이 특이하거나(스캔/벡터 이미지
PDF처럼 텍스트 자체를 못 뽑는 경우 포함) 예상 밖 레이아웃이면 실패할 수 있고, 이는
OCR이나 LLM을 붙여도 근본적으로 해결되지 않습니다(참고: OCR/LLM은 발견율을 높일 순
있지만 오인식·환각 위험이 있어 숫자값 신뢰도 면에서 더 위험할 수 있음). 그래서 "실패"
행은 값을 억지로 채우지 않고 **"공고 링크"** 컬럼으로 원문 상세페이지 바로가기를
제공합니다 — 실패 건은 이 링크로 들어가 직접 확인하는 것을 전제로 설계되었습니다.

## 동작 원리 (4단계)

1. **검색(step1_search.py)** — Playwright로 K-apt 메인 페이지 진입 후 메뉴 링크 클릭으로
   "사업자 선정(경쟁입찰) 결과 공개" 페이지 접속 (직접 URL 접근은 세션 미인증 에러 발생).
   지역/검색어/기간 필터 적용 후 전체 페이지를 순회하며 공고 목록 수집.
2. **상세/다운로드(step2_download.py)** — 공고별 상세페이지에서 정보 추출 및 첨부파일 다운로드.
   K-apt 자체 첨부파일이 없으면 "해당 공고 가기" 버튼으로 외부 대행 사이트에 진입해 원문을 확보.
3. **파싱(step3_parse.py)** — 다운로드한 PDF/HWP에서 텍스트를 추출하고, 자본금/실적/공법(특허)번호가
   적힌 줄을 정규식으로 찾아냄. 못 찾으면 사유를 값 대신 기록.
4. **엑셀 출력(step4_excel.py)** — 위 결과를 병합해 `.xlsx`로 저장, 실패 건은 빨간색으로 강조.

## 배포 (무료, 1~2인 테스트 규모)

계정 생성/저장소 연결/배포 버튼 클릭은 직접 하셔야 합니다. 아래는 그 준비물입니다.

### 백엔드 → Render (무료 웹서비스)

1. [Render](https://render.com)에서 GitHub 저장소(`beaever/k-apt`) 연결 후 "New Web Service" 생성
   - 이 저장소 루트의 `render.yaml`을 인식시키면(Blueprint) 자동으로 아래 설정이 적용됩니다.
   - 수동으로 만드는 경우: Root Directory `backend`, Runtime `Docker`, Instance Type `Free`
2. 환경변수 `CORS_ORIGINS`에 배포된 프런트엔드 주소(예: `https://your-app.vercel.app`)를 입력
3. 배포 완료 후 나오는 주소(`https://xxxx.onrender.com`)를 프런트엔드 환경변수에 사용

`DETAIL_CONCURRENCY`는 무료 티어의 적은 메모리(크로미움 여러 개 동시 실행 시 부족할 수 있음)를 고려해
`render.yaml`에서 기본 2로 낮춰뒀습니다. 필요하면 Render 대시보드에서 조정하세요.

**무료 티어 제약**: 15분간 요청이 없으면 인스턴스가 슬립되고, 다음 요청 시 재기동에 수십 초가 걸립니다.
1~2인이 가끔 쓰는 용도로는 문제없지만 상시 빠른 응답이 필요하면 유료 플랜이 필요합니다.

### 프런트엔드 → Vercel (무료)

1. [Vercel](https://vercel.com)에서 저장소 연결, Root Directory를 `frontend`로 지정
2. 환경변수 `NEXT_PUBLIC_API_BASE`에 Render 백엔드 주소 입력
3. 배포하면 `https://your-app.vercel.app` 형태의 주소가 생성됨

### 알려진 배포 한계

- Render 무료 인스턴스의 로컬 디스크는 재시작 시 초기화됩니다. "검색 → 엑셀 다운로드"를 같은 세션에서
  바로 이어서 하면 문제없지만, 시간이 많이 지난 뒤 다운로드를 시도하면 파일이 사라졌을 수 있습니다.
- 수집은 백그라운드 작업으로 실행되고 프런트엔드가 진행 상태를 폴링하므로, 검색 범위가 커서 오래 걸려도
  요청이 끊기지 않습니다. 단, 진행 상태는 서버 메모리에 있어 도중에 서버가 재시작되면 작업이 사라집니다.
- 메모리 보호를 위해 수집 작업은 서버당 1개만 동시에 실행됩니다(진행 중이면 새 요청은 거절).
- 24시간이 지난 작업 폴더(첨부파일·엑셀)는 새 작업이 시작될 때 자동 삭제됩니다.

## 알려진 제한사항

- 상세페이지/첨부파일 구조가 K-apt 자체 전자입찰, a2p.kr, kg2b.com 등 대행사별로 달라
  확인된 레이아웃 외의 새로운 형태가 나오면 파싱이 실패할 수 있습니다(이 경우 실패 사유가 표시됩니다).
- `.hwpx` 등 HWP/PDF 이외의 첨부파일 형식은 텍스트 추출을 지원하지 않습니다.
- 요건 값은 정규식/키워드 기반 추출이므로 문서 표현이 특이한 경우 놓칠 수 있습니다.
- K-apt 사이트 구조가 변경되면 selector를 다시 확인해야 합니다.
